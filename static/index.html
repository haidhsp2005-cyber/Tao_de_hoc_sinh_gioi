Hướng Dẫn Sử Dụng Hệ Thống Tạo Đề HSG

1. Lấy Google Gemini API Key:

Truy cập Google AI Studio, đăng nhập bằng tài khoản Google và tạo một API Key miễn phí. Dán vào ô "Google Gemini API Key" trên trang web.

2. Cơ chế AI Agent nhiều giai đoạn:

  • Giai đoạn 1: Lên ý tưởng bối cảnh, phát biểu bài toán rõ ràng, thiết kế bảng phân bố Subtask.
  • Giai đoạn 2: Phân tích thuật toán từ vét cạn Subtask 1 đến giải thuật tối ưu $O(\dots)$, lập trình code C++20 và Python 3.
  • Giai đoạn 3: Sinh và thẩm định chính xác 10 bộ Test Cases (từ ví dụ mẫu, biên nhỏ, Subtask 2, bẫy 64-bit, đến test cực đại).
  • Giai đoạn 4: Đóng gói file ZIP chuẩn chấm thi Themis / CMS.
